# CANmeleon Kvaser FD 固件特性与性能参数

支持 2xHS / 4xHS 模式；通道数按硬件与授权选择，性能与精度按表中标注的模式使用。

## 通信能力

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| CAN 通道 | 2xHS：2 路；4xHS：4 路 CAN / CAN FD | 每通道支持发送和接收；可用模式取决于硬件和授权。 |
| 报文格式 | 11 / 29 位 ID；Classic CAN 0–8 B，CAN FD 最高 64 B | 支持 Classic RTR；CAN FD 支持 BRS 开启 / 关闭。 |
| Classic CAN 速率 | 5 kbit/s–1 Mbit/s | 通过上位机设置总线速率。 |
| CAN FD 数据速率 | 最高 8 Mbit/s | 仲裁段与数据段独立配置；需配套支持相应速率的收发器和总线布线。 |
| 监听模式 | 支持 | 监听时不发送报文，也不向总线提供 ACK。 |

## 时间戳

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 接收硬件时间戳 | 支持 | 通过 CANlib 接收接口读取报文时间戳。 |
| 发送完成硬件时间戳 | 支持 | 通过 CANlib 开启 TXACK 后读取成功发送通知的时间戳。 |
| 时间戳分辨率（CANlib） | 默认 1 ms；可设置为 1 µs | 通过 canIOCTL_SET_TIMER_SCALE 设置时间戳步进。 |

## 典型通信性能

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 64 字节报文传输帧率（短时） | 2xHS：约 9,900 帧/秒 | CAN FD，启用 BRS；1 Mbit/s 仲裁 / 8 Mbit/s 数据；单条总线、双向合计。 |
| 64 字节报文有效数据吞吐（短时） | 2xHS：约 5.05 Mbit/s | CAN FD，启用 BRS；1 Mbit/s 仲裁 / 8 Mbit/s 数据；单条总线、双向合计。仅计算报文数据字段。 |

## 软件配套

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 配套软件 | 支持 CanKing | 安装 Kvaser 驱动。 |
| 开发接口 | 支持 Windows / Kvaser CANlib | 用于 CAN / CAN FD 应用开发。 |
