# CANmeleon GS USB 固件特性与性能参数

GS USB 模式；通道数由设备型号和授权决定。

## 通信能力

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| CAN 通道 | 支持 1 / 2 / 4 路 CAN / CAN FD | 可用通道数取决于设备型号和授权。 |
| 报文格式 | 11 / 29 位 ID；Classic CAN 0–8 B，CAN FD 最高 64 B | 支持 Classic RTR；CAN FD 支持 BRS 开启 / 关闭。 |
| Classic CAN 速率 | 最高 1 Mbit/s | 通过上位机设置总线速率。 |
| CAN FD 数据速率 | 最高 8 Mbit/s | 仲裁段与数据段独立配置；需配套支持相应速率的收发器和总线布线。 |
| 监听与回环模式 | 支持监听模式和内部回环 | 监听时不向总线提供 ACK；内部回环用于本机收发调试。 |
| 终端电阻控制 | 支持软件开启 / 关闭终端电阻 | 需配套软控终端硬件；设置用于当前运行会话。 |
| Classic CAN 原始 DLC 9–15 | 支持 | 数据帧仍携带 8 字节数据；保留原始 DLC 值。 |

## 时间戳

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 接收硬件时间戳 | 支持 | 开启硬件时间戳模式后读取报文接收时间。 |
| 发送完成硬件时间戳 | 支持 | 通过发送完成回显读取实际发送完成时间。 |
| 时间戳分辨率（WinUSB / SocketCAN） | 1 µs | 使用硬件时间戳；SocketCAN 需读取硬件时间戳字段。 |

## 典型通信性能

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 8 字节报文单向传输帧率（短时） | 约 22,000 帧/秒 | Windows WinUSB；四通道设备使用单条总线单向传输；CAN FD 标准帧，启用 BRS；1 Mbit/s 仲裁 / 8 Mbit/s 数据。 |

## 软件配套

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| Linux | 支持 SocketCAN | 使用 gs_usb 驱动。 |
| Windows | 支持 EcuBus | 使用 GS USB 设备接口。 |

## 不支持的功能与使用限制

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 单次发送 / 三次采样 / 非 ISO CAN FD | 不支持 | 使用自动重发、单次采样和 ISO CAN FD。 |
