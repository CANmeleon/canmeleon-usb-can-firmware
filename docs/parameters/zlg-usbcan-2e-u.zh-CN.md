# CANmeleon ZLG USBCAN-2E-U 固件特性与性能参数

ZLG USBCAN-2E-U 模式；需配套具备 2 路 CAN 接口及对应模式授权的设备。

## 通信能力

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| CAN 通道 | 支持 2 路 Classic CAN | 每通道支持发送和接收。 |
| 报文格式 | 11 / 29 位 ID；Classic CAN 0–8 B | 支持数据帧和远程帧（RTR）。 |
| Classic CAN 速率 | 5 kbit/s–1 Mbit/s | 通过上位机设置总线速率。 |

## 时间戳

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 接收硬件时间戳 | 支持 | 通过 ZLG API 读取报文接收时间。 |
| 时间戳分辨率（ZLG API 接收） | 100 µs | 报文接收时间以 100 µs 为步进。 |

## 软件配套

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| 配套软件 | 支持 ZCANPRO / ZXDoc / CANtest | 安装 ZLG 驱动，选择对应设备型号。 |
| 开发接口 | 支持 Windows / ZLG API | 使用 zlgcan.dll 进行二次开发。 |

## 不支持的功能与使用限制

| 参数 | 能力 / 数值 | 备注 |
| --- | --- | --- |
| CAN FD | 不支持 | 需要 CAN FD 时选择相应 CAN FD 固件模式。 |
